# 🛡️ CyberShield AI
CyberShield AI is an AI-powered cybersecurity platform built with Next.js, React, TypeScript, and Supabase. The project combines modern web technologies with AI capabilities to provide an intuitive and scalable cybersecurity-focused experience.

## 🚀 Features

* AI-powered cybersecurity assistance
* Modern and responsive user interface
* Secure authentication and user management
* Cloud-powered backend with Supabase
* Fast and scalable architecture
* Real-time data handling
* Clean and interactive user experience

## ⚡ Getting Started

### Clone the Repository

```bash
git clone https://github.com/tejasrirejeti-cloud/CyberShieldAI.git
cd CyberShieldAI
```

### Install Dependencies

```bash
npm install
```

### Configure Environment Variables

Create a `.env.local` file in the root directory:

```env
NEXT_PUBLIC_SUPABASE_URL=your_supabase_url
NEXT_PUBLIC_SUPABASE_ANON_KEY=your_supabase_key
```

### Run the Development Server

```bash
npm run dev
```

Open http://localhost:3000 in your browser.
